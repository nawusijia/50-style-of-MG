# 提示词迭代史

同一个片头，提示词改了几轮。每一轮都交给一个**没看过任何上下文的新 AI**，只给它这一版提示词，让它从零做出来，再请另一个独立的 AI 评审按六个维度打分（创意与惊艳、动效工艺、设计与排版、质感与细节、声音与同步、技术规格）。

| 版本 | 这一版提示词改了什么 | 评审结论 |
| --- | --- | --- |
| [v1](v1/) | 第一稿：5 个技法按时间排好，每段写清楚编号、旋钮和感觉 | 5.5 分。开场匀速像屏保；有一帧硬切；中间近 2 秒画面不动；最重的一拍画面上没动作 |
| [v2](v2/) | 要求“每一秒都在动、每个重拍都有动作”；开场加速蓄力；每个动作配专属音效；结尾改成老电视关机 | 6.2 分。节奏好了，但几个效果各演各的，没有一条线把它们串起来 |
| [v3](v3/) | 加了贯穿全片的主角：太阳炸开时留下的一颗红色像素，跳过每个字，变成句号，最后关机剩下的也是它 | 单独打 5.3 分，和 v2 对比创意胜出，但标题没写颜色，做成了一片灰白 |
| [v4](v4/) | 保留 v3 的主线，补上标题设计（红色立体厚度、黄色 AI）、粒子飞行路线、有和弦旋律的配乐 | 和 v2 并排对比：6.9 比 5.8，明显更好 |
| [v5](v5/) | 红色像素当“笔头”从头写出标题；每个拍点一个变化；标题不过曝；副标题加暗底；结尾句号回到画面中央 | 和 v4 并排对比：6.6 比 6.1，叙事、构图、字的工艺、音乐动态更好。**当前成品就是这一版** |

**结论：你没写清楚的地方，AI 只能猜。** v3 没写标题颜色，AI 就做成了灰白；v4 写清楚了，就对了。每一轮改的都不是代码，是提示词。

另外也要说实话：同一段提示词交给不同的 AI，做出来的细节会有差别。v5 的太阳就没有 v4 那么亮，因为提示词里没写“太阳要有光晕”。想锁住的东西，就要写进去。

每个文件夹里有那一版的 `PROMPT.md` 和一段 720p 预览视频。
