# 怎么把“看起来像什么”说成提示词

公式只有一句：

**编号（名字） + 旋钮（数字） + 感觉（比喻）**

- **编号**：在图鉴里找到最像的那张卡片，报它的编号和名字。AI 一下就知道是哪种技法。
- **旋钮**：卡片底下列着这个技法能调的参数。把你想要的写成数字：多少个、多快、多大、从哪到哪。
- **感觉**：最后加一个比喻，告诉 AI 整体是什么味道。

叫不出名字的时候，“像 #20，但是更慢、更黏”也是很好的描述。

---

## 示范一：粒子聚散成形 #02

**你原本会说**

> 我想要我的名字像沙子一样聚起来，再被风吹散。

**问题在哪**：沙子有多少颗？从哪里来？一起飞还是一颗一颗来？风从哪边吹？AI 只能猜。

**改写后**

> 用 **#02 粒子聚散成形**：约 3000 个粒子，从画面四周往中间聚成“娜乌斯嘉AI”；每个粒子出发时间随机错开 0–0.5 秒，缓入缓出；成形后停 1 秒，被一股从左往右的 **#27 噪声流场**吹散，像被风带走的沙。

| 部分 | 内容 |
| --- | --- |
| 编号 | #02 粒子聚散成形，#27 噪声流场 |
| 旋钮 | 3000 个；错开 0–0.5 秒；停 1 秒；从左往右 |
| 感觉 | 像被风带走的沙 |

## 示范二：挤压拉伸 #10 + 缓动 #09

**你原本会说**

> 来一个球掉下来，Q 弹一点。

**问题在哪**：“Q 弹”其实是两件事：形状会变，速度会变。形状在 #10，速度在 #09。

**改写后**

> 一个红色小球从顶部落下，弹三次，一次比一次低。用 **#10 挤压拉伸**：落地压扁到宽 1.5 倍、高 0.6 倍，下落最快时拉长到 1.3 倍，体积看起来不变；弹起用 **#09 缓动**里的回弹曲线；节奏卡在 120 BPM 的拍子上。

| 部分 | 内容 |
| --- | --- |
| 编号 | #10 挤压拉伸，#09 缓动 |
| 旋钮 | 弹三次；宽 1.5 / 高 0.6；拉长 1.3；120 BPM |
| 感觉 | Q 弹（由上面两个技法一起实现） |
